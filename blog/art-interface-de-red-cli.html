Deteción de tarjeta de red y configuración manual en Linux

En este artículo quiero hablar sobre cómo levantar el servicio de red de nuestro ordenador desde la línea de comandos(CLI). Esto es especialmente útil cuando estamos en medio de una instalación mínima de Linux en cualquiera de sus distribuciones y necesitamos acceso a internet para instalar paquetes.

Lo primero que debemos hacer es comprobar la interfaz de red disponible en nuestro equipo. Para ello, podemos usar el siguiente comando:

ip link

Este comando nos mostrará las interfaces detectadas.
lo:
enp3s0:eternet
wlx08a5c8ad8d7f:wi-fi

Si no contamos con un servidor DHCP que asigne automáticamente la dirección IP, el siguiente paso es configurar una dirección IP temporal de forma manual

sudo ip addr add 000.000.0.00 dev interface

Levantar la interfaz

sudo ip link set interface up

Configura la puerta de enlace por defecto para habilitar el acceso a internet.

sudo ip route add default via 000.000.0.0

Este comando envía tres paquetes ICMP al dominio para verificar si hay conexión a la red o a internet.

ping -c 3 desarrollocseg.com

Después de tener conexión a la red, comprobamos si están disponibles las utilidades dhclient o dhcpcd para gestionar direcciones IP mediante DHCP.

sudo apt update


sudo dhclient -h

Una vez instalada la utilidad, permite configurar la red automáticamente de forma persistente mediante DHCP.

sudo dhclient interaface

Con esto, ya dispones de conexión a internet a través de Ethernet, lo que te permitirá instalar paquetes y continuar configurando tu entorno en Linux.
